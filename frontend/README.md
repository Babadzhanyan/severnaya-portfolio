# Интерфейс портфеля «Северная» продолжает единый реестр

React 19.3.0 формирует пять разделов: портфель, инициативы, приоритеты, расчёт эффекта и план работы. Внутри разделов доступны воронка, трекер паспортов, карта завода, цифровая трансформация, направления и люди. Карта производства открывается в одном представлении

Команда редактирует данные в Google Sheets. Интерфейс проверяет источник каждые 15 секунд, сохраняет открытый раздел и показывает время последней проверки. Режим заседания увеличивает область управленческих визуалов

## Запуск и сборка

`npm ci` устанавливает зафиксированные зависимости

`npm run dev` открывает разработку на localhost5173

`npm test` проверяет денежные ограничения, дельты, сроки и совпадение производственной модели с серверным эталоном

`npm run build` формирует папку `dist` для GitHub Pages

`npm run preview` открывает собранный выпуск на localhost4173

## Источник связывает сайт с Google Sheets и сервером

`public/runtime-config.js` задаёт `apiBase`. Пустой адрес включает прямое чтение Google Sheets. Указанный адрес подключает FastAPI; при временной недоступности сервера сайт читает Google Sheets и сохраняет время проверки

`GET /api/portfolio` возвращает `{portfolio, synced_at, source_status}`. `portfolio` содержит проекцию PMOData: 58 полей паспорта, команду, сроки, решения, фактические результаты, финансовые модели и происхождение значений

`GET /api/calculators/source` передаёт фактический производственный сценарий, учебный пример и схему полей

`POST /api/calculations/production` проверяет личный производственный сценарий той же моделью, которую браузер использует при прямом чтении Google Sheets

Исходный сценарий Google формируется формулой в `Калькулятор EBITDA!K2`. Личные изменения остаются в текущем браузере. Решение о согласовании эффекта оформляется в общей таблице

## Два свода отвечают на разные управленческие вопросы

Воронка показывает стадию, количество, сопоставимую дельту, годовой потенциал до затрат ИТ, EBITDA 2027 после расходов ИТ, деньги 2027 и плановые платежи внедрения. Дельта появляется после фиксации подтверждённого сопоставимого предыдущего среза

Полный трекер содержит все действующие карточки. Объединённые инициативы сохраняют прежние коды в архиве текущего паспорта. Рабочий фильтр показывает выбранный состав. Код открывает паспорт. Пять дат L1–L5 связываются с решением владельца и фактическим подтверждением

Воронка печатается отдельным однолистником; полный трекер повторяет заголовок на каждой странице; основной паспорт печатается отдельно от архива 58 полей

Подробный план открывается после подтверждённого запуска L3. Сроки пяти стадий доступны с момента входящего предложения

## Производственная модель связывает рычаги с конечным результатом

Наблюдаемая база сохраняет фактические головы и кг исходного периода. Изменение операционного параметра задаётся в процентах или процентных пунктах. Материальный баланс маршрутов включает продажи, потери, запасы и добавочную массу ингредиентов

Мост использует постоянный порядок: объём → структура → цена → переменные расходы → постоянные расходы. Пустые ставки сохраняют физический результат и закрывают допуск EBITDA. Спрос и мощности проверяются отдельно

Личный сценарий показывает оценку. Подтверждённая сумма портфеля требует согласованную производственную базу, выходы, расходы, спрос, мощности и календарь запасов


## Шесть уровней связывают инициативы с областью изменения

Ц0 – устойчивый ИТ-контур; Ц1 – автоматика и первичные данные; Ц2 – управление производством; Ц3 – учёт и цифровые процессы; Ц4 – единые данные и интеграции; Ц5 – аналитика и искусственный интеллект

Каждая инициатива получает один основной уровень из Google Sheets. Уровень обозначает область изменений; стадия L0–L5 показывает готовность и допуск. Вершина пирамиды объединяет результаты бизнеса для всех уровней

Фильтры уровня, направления, куратора, ответственного, участка, стадии, решения и поиска связаны. Пирамида сохраняет распределение по уровням для остальных выбранных условий; нажатие уровня выбирает карточки и связанные направления / людей

Раздел «Направления и люди» группирует инициативы по команде, куратору, ответственному и участку. Раздел цифровой трансформации показывает уровни Ц0–Ц5

Паспорт содержит уровень и цепочку: инициатива → показатель / база и цель → критерий приёмки → эффект. Пакетная печать формирует отдельную страницу каждой карточки из текущего фильтра
