# Северная / Портфель инициатив ИТ 2027

React показывает портфель, воронку, сроки стадий, карту производства, команду, паспорта, расчёты и план четырёх встреч

Google Sheets служит единым источником и формой ввода. Сайт обновляет данные каждые 15 секунд и сохраняет последний проверенный срез

Поле apiBase в runtime-config.js подключает FastAPI после размещения сервера. Текущий выпуск читает Google Sheets напрямую

Изображения карты создают предметные иллюстрации этапов. Подписи, связи и коды формирует React
