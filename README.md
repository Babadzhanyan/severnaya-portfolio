# Северная / Портфель инициатив ИТ 2027

React связывает обзор, воронку и трекер, сроки стадий, карту производства, цифровую трансформацию, направления и людей, паспорта, расчёт эффектов, приоритеты и план четырёх встреч

Google Sheets служит единым источником и формой ввода: 195 карточек, 58 полей, шесть цифровых уровней, пять сроков L1–L5. Сайт проверяет обновление каждые 15 секунд и сохраняет последний корректный срез

172 исходных проекта и 23 идеи доступны вместе. История содержит 52 завершённых проекта и один отменённый; рабочий состав включает 142 позиции. Исходные факты исполнения и роли сохраняются по кодам. Семь связанных фильтров постоянно видимы
