# Северная / Портфель инициатив ИТ 2027

React открывает пять основных разделов: портфель, инициативы, приоритеты, расчёт эффекта и план работы. Портфель связывает воронку, трекер, сроки стадий и единую карту производства; паспорт раскрывает выбранную инициативу

Google Sheets служит единым источником и формой ввода: 200 карточек, 58 полей, шесть цифровых уровней, пять сроков L1–L5. Сайт проверяет обновление каждые 15 секунд и сохраняет последний корректный срез

172 исходных проекта и 28 идей доступны вместе. История содержит 52 завершённых проекта и один отменённый; рабочий состав включает 147 позиций. Исходные факты исполнения и роли сохраняются по кодам. Семь связанных фильтров постоянно видимы

Сотрудники проверяют карточки к 13 октября, 18:00; руководители подтверждают распределение к 14 октября, 18:00. Дмитрий Петров курирует проектный офис; Сергей Белов утверждает портфель

Поле apiBase в runtime-config.js подключает FastAPI после размещения сервера. Текущий выпуск читает Google Sheets непосредственно. Сервер FastAPI и PostgreSQL подготовлен и проверен локально

Расчёт использует реальные производственные и годовые исходные показатели. Предварительный годовой прирост EBITDA составляет 55,014 млн руб для полного рабочего состава; финансовая служба подтверждает оценки отдельно. Приоритеты сопоставляют прибыль, ресурсы и сроки. План четырёх встреч содержит задания, сообщения и три видео с русскими субтитрами
