# Система связывает реестр инициатив, приоритеты и расчёт эффекта

Google Sheets хранит 200 карточек и расчётные параметры. React открывает пять разделов сайта: портфель, инициативы, приоритеты, расчёт эффекта и план работы. FastAPI проверяет источник каждые 15 секунд. PostgreSQL сохраняет версии и атомарно переключает текущий срез

[Сайт проектного офиса](https://babadzhanyan.github.io/severnaya-portfolio/) и [единый реестр](https://docs.google.com/spreadsheets/d/1stFDS_18dulhc96CSybYdXDk3RyvMvsSO9HxPkTvB4g/edit) образуют рабочий контур

## Два каталога разделяют интерфейс и сервер

- `frontend` содержит React, визуалы, калькуляторы и проверки
- `backend` содержит FastAPI, схему PostgreSQL, контейнеры и проверки источника

## Локальный запуск поднимает сервер и интерфейс

1. В каталоге `backend` скопируйте `.env.example` в `.env` и задайте случайный `POSTGRES_PASSWORD`
2. Выполните `docker compose up --build -d`; сервер открывается на `http://127.0.0.1:8000`
3. В каталоге `frontend` выполните `npm ci`, затем `npm run dev`; интерфейс открывается на `http://127.0.0.1:5173`
4. Для подключения интерфейса к серверу задайте `apiBase:"http://127.0.0.1:8000"` в `frontend/public/runtime-config.js`

Пустой `apiBase` включает прямое чтение общей Google Sheets. Обновления реестра сохраняют выбранный раздел, фильтры и личный сценарий расчёта

## Проверки подтверждают целостность и денежную логику

`npm test` запускает проверки моделей интерфейса. `npm run build` формирует `dist` для GitHub Pages. Серверные проверки описаны в `backend/README.md`

Паспорт сохраняет 58 полей, происхождение значений, факт исполнения и отдельное финансовое согласование. Дедлайн содержит время Москвы. Оценка стоимости складывает внутренние часы по начисленной зарплате, оборудование, договоры и сопровождение. Интерфейс показывает управленческую операционную прибыль после текущих расходов. Модель сохраняет исходные финансовые поля для совместимости

## Публичный сайт читает Google Sheets на GitHub Pages

Ветка `pmo-site` содержит собранный сайт. Ветка `app-source` содержит исходный код системы. Требуется подтверждение: площадка FastAPI и PostgreSQL для общего серверного доступа, адрес HTTPS и регламент резервного копирования

Текущий публичный сайт использует прямое чтение Google Sheets. Личный сценарий расчёта остаётся в текущем браузере; общий реестр принимает утверждённые данные команды

## Текущий интерфейс упрощает проверку инициатив

Названия карточек очищаются от служебных ссылок на источники; исходное название сохраняется в реестре. Передел объединяет все площадки. Трансформация связывает уровень, команду, ответственного и инициативу; список показывает 20 записей на странице. Паспорт использует одну карточку

Калькулятор показывает операционные параметры, итог прибыли и изменённые входы. Оценки доступны для всех 200 кодов; 147 текущих инициатив имеют предварительный расчёт. План содержит четыре встречи, задания участников и три актуальные видеоинструкции. Служебные черновики сообщений хранятся в рабочем архиве проекта
