# Экран портфеля инициатив

Экран читает реестр XLSX в браузере и показывает портфель, стадии, Гант, карту переделов, направления и паспорта

Пользователь загружает локальный реестр, проверяет карточки и скачивает обновлённый XLSX либо пакет правок для объединения. Excel пересчитывает финансовые формулы после сохранения. Книга содержит исходные сведения и цвета происхождения

Файлы сайта содержат интерфейс, справочник полей и библиотеки. Производственные показатели и персональные сведения поступают только из выбранного пользователем файла и обрабатываются в браузере

Главная страница: index.html
